# Architecture Decision Records

An ADR records a decision that would otherwise be rediscovered or argued repeatedly.

Create a new numbered file when changing architecture, storage, contracts, deployment shape, security policy, or required quality gates. Keep old ADRs; mark them superseded instead of rewriting history.

Template:

```markdown
# NNNN — Decision title

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context

What problem and constraints require a decision?

## Decision

What will the team do?

## Consequences

What becomes easier, harder, or deliberately excluded?
```
